# v0.7.16：无地址需处理任务一键筛选与安全批量恢复

本版本基于正式版 `v0.7.15` 制作，仅新增任务中心“尚无可访问地址”筛选及批量“一键恢复”能力，保留 `v0.7.15` 的队列诊断、停止确认与稳定建站流程，不包含开发工作区中未提交的 `0.7.14` 阶段标签页及负责人流程改动。

## 主要改进

- **“需处理 · 尚无可访问地址”一键筛选与地址子筛选**：
  - 任务中心工具栏新增 **「需处理 · 尚无可访问地址」** 快捷筛选按钮并实时显示计数，点击一次即可筛选 `需要处理` 且尚未获得合法 HTTP(S) 可访问地址（包括等待创建生成站与已建站但尚无域名）的任务，再次点击恢复全部。
  - 在「交付状态」选择「需要处理」时，工具栏同步显示可访问地址下拉筛选（`全部需要处理` / `尚无可访问地址` / `已有可访问地址`），切换离「需要处理」时自动重置。
- **多选安全批量「一键恢复」**：
  - 任务中心基于轻量索引投影每行可恢复动作（`resume` / `adjust-site-names` / `confirm-stopped`），不额外读取全量任务历史或明细。
  - 多选任务后可在操作栏点击 **「一键恢复」**，依次复用单任务恢复接口（`POST /api/automation/tasks/:id/resume` 或 `adjust-site-names`）提交恢复。
  - 批量操作严格保留既有安全边界：不传递 `force: true`、不自动跳过未确认停止（`confirm-stopped`）或存在同站活动执行的任务；已成功恢复项自动取消勾选，跳过或失败项保留勾选并在操作栏下方展示可跳转到对应执行记录的原因清单。

## 升级与验证边界

- 请通过原安装目录的 `npm start` 启动，在侧栏版本号或「系统设置 → 检查更新」中检查并安装更新；既有队列诊断、配置、数据与凭证均保留。
- 验证覆盖任务中心相关 Node 接口测试、索引性能测试、Vue 组件测试、全量 TypeScript / Vue 类型检查、打包测试及生产构建，并已在本地 `127.0.0.1:4180` 服务完成交互验收；未执行 Windows 实机在线升级或真实外部模型/Kooboo 生成调用。详情见 `docs/release-validation-0.7.16.md`。
