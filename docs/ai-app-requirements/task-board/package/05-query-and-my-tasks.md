# 查询、筛选与任务视图

状态：查询、排序和精确截止时间规则已确认。项目内“仅看我的任务”必做，跨项目汇总不提供。

## 项目任务视图

- 同一项目提供看板和列表两种任务展示，可切换，展示同一批任务。
- 视图与搜索均受当前项目成员权限约束，不扩大任务访问范围。
- 常规看板与列表及其搜索默认隐藏归档任务；项目内提供用户主动进入的“归档任务”列表，支持同样的搜索与筛选，任务仍只读。

## 搜索与筛选

- 在当前项目按任务标题和描述进行关键词搜索，不搜索评论正文。
- 支持状态、负责人（含未分配）、优先级、标签、截止时间及是否逾期筛选。
- 状态与标签使用当前项目的配置；截止时间统一 UTC 保存、按用户时区显示，逾期按实际时间点比较，遵守 [时间模块](09-time-and-timezones.md)。
- 标题或描述任一包含关键词即命中，忽略英文字母大小写；描述按可阅读文字搜索，不匹配 Markdown 标记或图片链接地址。
- 搜索与不同筛选维度之间同时满足，同一维度多选时满足任一项即可；多个标签也按任一标签匹配。
- 截止时间支持按起止日期范围筛选，包含起止当天；范围按查询所用的用户时区解释，并转换为 UTC 时间点边界查询。可单独筛选“未设截止时间”；无截止时间及已完成任务均不算逾期。

## 排序与筛选后的操作

- 看板保留配置的列顺序和已有手动任务顺序，筛选只隐藏不匹配任务；新建、跨列移动及恢复任务仍遵守既有列末尾规则。
- 列表默认最新创建在前，可按截止时间或优先级排序，按截止时间排序时无截止时间任务排末尾。
- 列表提供手动排序模式，拖拽结果保存为当前项目共享顺序，与看板列内顺序分别保存。
- 切换到创建时间、截止时间或优先级等字段排序时，不覆盖已保存的手动顺序；切回手动模式恢复该顺序。
- 排序方向、并列项及列表手动模式中新建/恢复位置采用 [整理默认 R05](10-fields-and-ui.md)，与看板列末尾规则分别保存。
- 筛选后仍可打开任务，按原权限编辑或切换状态；操作后不再匹配的任务退出当前结果。
- 筛选生效时暂停看板同列拖拽排序及列表手动拖拽，清空筛选后恢复；跨列移动仍按目标列末尾规则。
- 同一项目切换看板与列表时保留查询条件，提供一键清空；切换项目重置为该项目默认条件，不要求跨会话记忆。

## 数量与空结果

- 展示当前匹配任务数，看板各列数量按筛选结果计算。
- 无结果显示空状态并允许清空条件，不改变底层任务数据。
- 不增加独立统计报表。

## 项目内“仅看我的任务”

- 必须支持当前项目内“仅看我的任务”的快捷筛选，含义为负责人是当前登录用户。
- 看板和列表均支持该筛选，与关键词及其他维度沿用既有组合规则；同项目切换视图时保留。
- 关闭后撤销该本人负责人限制，其他查询条件继续生效；不修改任务数据或分配关系。
- 快捷开关与负责人控件协调采用 [整理默认 R06](10-fields-and-ui.md)，避免两个互相矛盾的负责人条件。
- 沿用常规视图默认隐藏归档任务的规则，不自动排除已完成但未归档的本人任务；归档任务须主动进入归档列表查询。
- 退出或被移除后不得继续查询该项目。
- 不提供跨项目“我的任务”汇总页面；此前将跨项目汇总列为可选的决定已被当前排除范围替代。

## 可观察的预期结果

- 同一项目可以切换看板与列表，任务内容及访问范围一致。
- 可以通过任务标题或描述找到当前项目任务，不将仅命中评论正文的任务纳入搜索结果。
- 例如选择高优先级及标签 A、B，结果须为高优先级并具有 A 或 B 至少一个标签。
- 截止日期范围包含所选用户时区的起止整天，转换为对应 UTC 范围查询；未设截止时间可单独查询，不被算为逾期。排序按实际到期时刻比较。
- 归档任务只在主动进入的归档列表中查询，常规结果不混入；查询不解除只读限制。
- 列表初始按创建时间倒序，可使用截止时间、优先级排序，也支持手动拖拽调整顺序。
- 手动模式下调整的列表顺序刷新后保留，并由同项目成员共享；切换字段排序不覆盖该顺序，看板列内顺序不随列表排序改变。
- 筛选生效时，看板只显示匹配任务且列数量随之变化；可跨列移动，但不能同列拖拽排序。
- 同项目切换两种视图保留条件，切换项目重置；无结果可清空条件重新查看。
- 在项目内开启“仅看我的任务”后，仅展示当前用户负责且满足其他条件的任务；看板与列表切换保留，关闭后可恢复其他负责人任务的查询。
- 开启本人筛选不改变归档隐藏、完成状态及访问权限规则，不混入其他项目的本人任务；不要求实现跨项目汇总页面。
