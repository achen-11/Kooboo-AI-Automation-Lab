- 项目及任务仅项目成员可见，由项目管理员添加成员。

## 生命周期讨论过程

下表保留最初候选。用户基本认可归档、恢复规则，并修正了删除范围：归档类似软删除，真删除也必须提供，仅管理员可删除。最终决定见 D016、D017；“首版暂不提供永久删除”未被采用。

| 主题 | 建议 |
| --- | --- |
| 项目状态 | 支持进行中和已归档；新项目为进行中 |
| 项目归档 | 项目管理员可归档；从默认项目列表收起，成员可在已归档列表查看；归档后项目信息、看板和任务只读 |
| 恢复与成员权限 | 项目管理员可恢复；归档期间保留成员管理和主动退出能力，继续遵守最后一名管理员保留要求 |
| 项目删除 | 首版通过归档保留项目与历史，暂不提供永久删除；如需删除另行明确删除范围与恢复能力 |

项目是否有未完成任务不作为归档前置条件；未完成任务在归档后仍保留原状态。归档与恢复已写入正式需求。
