## 交付方式与限制

使用干净提交生成正式 ZIP、SHA-256 文件和 `UPDATE_MANIFEST.json`，发布脚本要求远端版本标签与清单提交完全一致，先创建草稿、上传完整附件后才设为正式最新版。更新继续保留原完整数据目录与失败回滚机制；不通过改写旧任务来升级流程。

最终包的文件哈希、源码提交绑定、解压启动与远端附件完整性在打包后另外校验，以实际发布回执为准。以上验证不等同于 Windows 实机在线升级、真实模型生成、远端 Kooboo 操作、浏览器视觉验收或同事故障根因确认。
