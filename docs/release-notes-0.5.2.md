# v0.5.2

本版本修复建站域名配置与香港根域名处理，并调整换绑入口。

- 资源导入支持 `siteName`、`subDomain`、`rootDomain`，单资源新建任务可覆盖名称；批量任务沿用各资源配置。名称配置随输入版本和任务固定，未指定时才生成 `auto_…` 名称。
- 自定义名称创建前检查站点名和子域名占用；结果不确定时按原名称核对，避免重复建站。
- 正确识别香港后缀 `-shawnchen-hk.kooboo.io`，拼接时保留一个分隔符，换绑回填不再把根域名片段混入子域名；兼容旧配置省略前导 `-` 的情况。
- 任务详情“换绑域名”增加链接图标，任务中心列表移除该入口；可从任务详情继续换绑。

现有站点不会因升级自动换绑。旧地址需要调整时，请在任务详情“更多 → 换绑域名”中操作。

验证：隔离源码的 58 项相关测试、服务端 TypeScript 检查及生产构建通过。未执行真实模型、远端 Kooboo、浏览器或 Windows 实机验收。

本次发布不包含其他尚待验证的任务恢复、评测优化及界面改动。
