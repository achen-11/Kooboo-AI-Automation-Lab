# 字段、编号与界面规则

状态：字段与界面组已由用户整体确认（D124—D129），并补充列表点击打开详情抽屉（D130）。文末 R01—R07 是整理时补充的默认，供整体复核，不能当作用户逐项原话。资料版本为 `task-board-requirements-v1.0-review`。

## 编号与名称

- 每条任务由系统生成稳定编号，如 `#0001`；用于卡片、详情、操作记录和重名区分。编辑、完成、归档及恢复均不改变编号，真删除后也不复用。
- 标题、项目名称、列名及标签名去除首尾空白后不能为空；项目名称、任务标题可重名。项目仍有独立身份，不因同名合并。
- 同项目列名及标签名分别不可重名，英文忽略大小写；不同项目互不影响。具体长度上限由实施阶段合理设置并在输入处提示，不静默截断。

## 颜色与系统字段

- 标签创建者可选颜色，不选使用默认；后续仅管理员能修改标签颜色、重命名及删除。列颜色继续仅管理员维护。
- 任务编号、创建人、创建时间及最后更新时间不可手动改写。
- 任务字段、状态、负责人、标签关联、归档及恢复发生实际变化时更新最后更新时间。查看、排序、评论操作和未发生变化的保存不更新任务时间；评论单独记创建与编辑时间。
- 时间由服务端记录，统一 UTC 保存，按用户时区显示，遵守 [时间模块](09-time-and-timezones.md)。完成时间有独立含义，不被一般编辑时间覆盖。

## 页面与操作入口

| 页面或区域 | 必需内容与操作 |
| --- | --- |
| 项目入口 | 当前参与项目、主动查看归档项目、创建项目；进入项目后使用该项目角色 |
| 项目看板与列表 | 搜索、筛选、仅看我的任务、视图切换、匹配数量、创建任务、主动进入归档任务列表 |
| 看板卡片 | 标题、编号、负责人或未分配、优先级、截止时间、标签；状态由所在列体现 |
| 任务详情 | 编号与系统时间、可编辑业务字段、Markdown 描述、评论、倒序操作记录，按权限提供归档恢复或真删除 |
| 项目设置 | 项目信息、成员与角色、列及默认/完成列、颜色、标签、项目记录、归档恢复与真删除 |
| 通知入口 | 未读数、通知列表、单条/全部已读、关联目标；个人邮件开关与显示时区设置 |

- 未设截止时间、无标签等空值不显示误导性数据；编辑入口仍能填写，负责人清楚表示未分配。
- 任务列表点击任务行或标题打开该任务的详情抽屉（drawer），在抽屉内查看及按权限编辑上述详情；归档任务列表同样可打开但只读。抽屉与列表显示同一任务数据，保存后的字段和状态变化反映到列表及看板。
- 抽屉同时适配桌面与手机窄屏，不得因以抽屉展示而遗漏描述、评论、记录，或绕过归档及失权限制。
- 时间可通过紧凑显示及详情展示明确时区，不能只给一个含义不明的钟面时间；以可读布局表达层级，避免重复次级说明。
- 桌面支持完整看板、同列及跨列拖拽和列表手动排序。手机支持查看、新建、编辑、Markdown 评论、图片预览、通知和状态切换；必须有无需拖拽的状态入口。
- 所有入口按 [权限矩阵](11-permissions.md) 约束，最终权限由服务端重新检查；界面隐藏按钮不能代替权限判断。

## 整理默认：供整体复核

| 编号 | 默认处理 | 来源与边界 |
| --- | --- | --- |
| R01 | 编号在当前应用范围唯一递增，最少四位补零；`#9999` 后为 `#10000`，不截断、不循环、不按年重置。并发不重号，允许间断，不暴露非成员任务内容。内部标识与展示编号可分开 | 用户只明确外观和稳定性；递增范围与溢出处理为整理补充，不是 Kooboo 已提供能力的声明 |
| R02 | 管理员可自行降级，但须有其他管理员；身份变更与退出、移除并发时服务端仍确保至少一名管理员。同人重复添加不创建重复关系，过期请求提示当前状态 | 由至少一管理员、失败与并发规则整理；是否采用何种事务或版本字段由实现决定 |
| R03 | 初始列与新增列、标签都有可辨颜色，不要求固定色值。历史事件保存相关标识及当时可读名称，后续改名不重写过去事件 | 颜色细节与历史快照为整理补充；不保存历史正文或恢复版本 |
| R04 | 评论、描述与名称的技术长度上限由实现合理确定并提示；超限保留输入、拒绝保存，不截断。颜色选择与 Markdown 库选型由实现适配 | 用户已授权合理技术长度及第三方库；此处统一应用到正文与评论 |
| R05 | 截止时间排序从早到晚、空值最后；优先级紧急到低；相同值以创建时间倒序、内部稳定标识确定顺序。列表手动模式新建/恢复任务放末尾，跨状态不改列表手动位置 | 默认方向、并列项及列表新增位置为整理补充；不改变用户确认的看板列末尾及两套顺序独立规则 |
| R06 | “仅看我的任务”与负责人控件表示同一个负责人维度；开启时选择当前用户，手动改选其他负责人时关闭快捷开关，避免隐含矛盾条件；其他维度保持 | 按已确认的本人含义及维度组合规则整理；不增加跨项目查询 |
| R07 | 样例编号只在干净测试应用里预期从 `#0001` 开始，已有数据时记录实际映射，不重置或占用真实编号；样例使用相对验收时刻重建时间 | 仅样例执行约定，不规定新导入接口或要求改动生产时钟 |

这些默认在整体复核有修改时，需同步需求、样例、验收与资料版本；不增加新的产品阶段。
