# AI Site 模板逐屏取证

2026-11-10：AI Site 模板的生成参考研究和独立评测改为真实滚动后的视口截图，避免入场动画、懒加载内容未进入视口就被 fullPage 截为空白。

## 两个执行端

- Kooboo AI Chat 的生成研究：固定任务提示要求通过 `function_discover`、`use_function` 加载 Kooboo 的 `take_page_screenshots` 和 `read_image` 实际 schema，程序采集后按需看图。工具不存在或返回 `unsupported` 时停止该视觉研究阶段并保留缺口，不回退旧截图工具。
- Automation Lab 的独立评测：复用本轮独立 Playwright 会话，通过 `browser.mjs` 的 `action="take_page_screenshots"` 执行相同方式的逐屏采集。此操作由 Lab 本地执行，并非远程调用 Kooboo 函数；截图直接进入本轮证据目录，保持当前站点修订、输入版本及来源快照的绑定。

桌面视口为 1440×1000，移动视口为 390×844。每次按实际滚动位置向下前进约 85% 视口高度，保留重叠。每屏检查可见图片、字体、有限动画、布局和可见文字的稳定性，连续稳定 500ms 后取证；单屏默认最多等待 4 秒。JS 计数器文字变化也会重置稳定窗口。

`scope="regions"` 接受从真实页面确认的唯一 CSS 选择器，超高区段仍按视口分屏。缺失、多匹配、隐藏、嵌套滚动、横向溢出及滚动停滞等可检测缺口会明确返回。该路径只覆盖主文档，不能证明所有嵌套滚动容器、任意延迟状态、Canvas、视频或背景图均已完成。

## 程序计划、恢复与缓存

程序继续按固定清单覆盖入口、静态路径、模板样本及桌面/移动视口。每个 URL / 角色 / 视口调用最多采集 16 屏；达到数量上限后按实际 `nextStartY` 自动续采。每项最多进行 4 批，并在批次间检查 120 秒上限，导航或在途操作可增加实际耗时。达到上限、超时或存在未稳定画面时，保留已保存帧和缺口，不能声明完整。

每帧保存独立 PNG / JSON，登记 SHA-256、URL、实际滚动位置、文档/视口尺寸、readiness、区段信息及任务绑定。每帧保存后立即做任务检查点。完整批次和可续采的有效前缀还会保存到采集登记表；恢复时验证所有字节、绑定和每帧观察，完整项复用，有效前缀按游标续采。未知或损坏状态需要重新取证。

采集策略升级为 `viewport-evidence-pc1440-mobile390-v3`。旧策略的单张 fullPage / 观察记录不能作为新策略的完整截图缓存，也不能继续用于活动 AI Site 模板评测。历史报告及其原件保留；升级代码不自动恢复任务或发起付费评测。

`nextStartY` 包含重叠，不是第一处未覆盖像素。完整覆盖需按全部实际 `scrollY` 与 `viewportHeight` 检查连续区间；单张首屏、页脚图或某个 region 的 complete 都不能代替全页范围。程序事实表保留全部帧引用，缺帧、部分覆盖或未稳定时不能将页面项标为 verified。最终报告同时保留目标或参考页的程序取证缺口，模型通过不能消除这些缺口。

## 供 AI 按需查看

`review-input.json` 是按本批路径与视口筛选的逐屏目录，保留同 URL 的所有计划帧及其位置；不再将同 URL 去重为一张图，也不再生成长图切片。模型按当前判断选择原始图片，不能把目录、HTTP 成功或图片加载计数当成已经看图。未查看范围和无法解释的空白/纯色区域应明确记录，不推断原图内容或归因。

当前状态或交互前后取证仍可使用单视口 `snapshot` / `screenshot`；AI Site 模板会话在运行时拒绝 `fullPage:true`。页面补采使用：

```sh
node browser.mjs '{"action":"take_page_screenshots","role":"target","viewport":"desktop","url":"https://target.example/","scope":"page","maxScreenshots":16}'
```

续采时保持 URL、角色、视口和范围不变，将返回的 `nextStartY` 作为 `startY`；区段续采还需保留 selectors 并使用 `nextSelectorIndex`。回执仅含目录和元数据，不自动附加全部图片。

## 验证边界

针对性测试使用虚拟 DOM/时钟、模拟 Playwright 页面与本机测试接口，覆盖生产稳定性脚本、滚动与限额、逐帧落库、续采、缓存失效、证据索引、完整度降级及独立评测闭环。测试不会启动真实 Chromium，也不会调用外部模型。

真实网站的动效、懒加载和视觉效果仍需另行验收。实现不修改运行数据、已发布规则快照或已有报告，不自动重启服务或恢复停止任务。部署新版服务后，新执行及显式恢复的流程使用此策略。
