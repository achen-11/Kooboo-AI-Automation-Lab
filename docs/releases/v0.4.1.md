# v0.4.1 — 手动在线更新

## 新增

- 点击侧栏版本号或“系统设置 → 检查更新”，查看 GitHub 正式版本和更新说明。
- 交付包支持手动下载、校验、安装及平台重启，显示下载进度并在重启后重新连接。
- 安装前检查活动任务，完整备份数据和加密配置；新版启动失败时恢复匹配的代码与数据。
- 提供更新包制作、发行附件校验和 GitHub Release 发布脚本。

## 首次安装与旧包接入

下载本页 `automation-lab-0.4.1.zip`，解压后按 `READ_FIRST.md` 安装 Node.js 24+、npm 依赖和 Chromium，并运行 `npm start`。

已使用旧版的用户需要停机并备份整个实际数据目录，再按交接指南迁入此次交付包；`.data/` 与其中主密钥必须一并保留。之后可以使用界面内的更新入口。

GitHub 自动生成的 Source code 归档不是交付安装包。开发源码目录可以检查版本，在线安装需要使用交付包的启动器。

## 验证范围

更新事务、安装包校验、进程切换与失败恢复已通过定向自动化测试及构建检查。Windows 实机与真实 GitHub 附件升级仍待验收；首个发行版本主要用于首次安装及接入更新器。
