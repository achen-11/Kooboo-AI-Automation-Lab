# 正文图片与资源清理

状态：业务规则已确认；具体存储、鉴权及备份方式随生成实现与交付要求适配，尚未实际验证上传及清理。

## 图片插入与保存

- 描述与评论支持选择图片、粘贴截图、拖入图片。
- 先上传取得可引用链接再插入 Markdown；正文不保存 Base64、data URL 或临时本地预览地址。
- 上传中提供进度或状态，失败明确提示并可重试；上传未完成或失败时，不能提交包含这些占位图的正文，须重试成功或移除占位图后保存。
- 从正文移除图片先移除对应引用，不直接删除仍可能被其他内容使用的资源。

## 格式、预览与权限

- 支持 JPG、PNG、WebP、GIF，单张不超过 10 MB。
- 图片在正文中显示，可点击放大预览；不提供独立附件管理入口。
- 图片增删属于正文编辑，任务描述及评论分别沿用已有编辑权限，不引入单独上传者管理权限。
- 图片查看受项目成员权限保护，离开项目后持有链接不能继续访问。
- 项目或任务归档后仍可查看图片，但不能修改正文。

## 资源清理

- 移除正文引用、删除评论、真删除任务或项目后，清理不再被有效正文引用的图片。
- 同一图片仍被其他有效内容引用时不得误删，清理不得破坏仍可访问的其他正文。
- 取消编辑或未保存的上传可延迟清理，不得干扰正在编辑的有效上传。
- 归档不清理图片；图片资源不因日志保留而复制或长期保留历史正文版本。

## 可观察的预期结果

- 三种插入方式均先上传取得链接，保存后重新打开可显示图片；正文没有 Base64 或临时预览地址。
- 不支持的格式和超过限制的图片有明确反馈，上传失败可重试，含未完成占位图的正文不能被当作成功保存。
- 合法格式可正文展示并放大预览，非成员不能通过图片地址绕过项目权限。
- 无正文编辑权限的人不能增删图片，归档内容的图片仍可按权限查看。
- 移除最后有效引用后资源可清理，多处仍在使用的图片不会因删除其中一处而损坏；归档不会删图。
