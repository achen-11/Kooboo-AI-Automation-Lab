## 最后一组产品规则建议

| 主题 | 建议 |
| --- | --- |
| 任务标识 | 系统生成稳定、可显示的任务编号，用于区分重名任务、详情与日志；编辑、归档恢复不变，不将已删除任务编号重新分配给其他任务 |
| 名称校验 | 必填名称及标题去除首尾空白后不能为空；项目名称和任务标题允许重名，依编号区分；同项目列名及标签名不允许重名，英文忽略大小写，不同项目相互独立；具体技术长度限制由实现合理设置并明确提示 |
| 标签颜色 | 标签可设置颜色，创建时创建者可选，未选使用默认颜色；后续调整颜色由项目管理员维护，继续遵守已有创建、重命名和删除权限 |
| 更新时间 | 任务字段、状态、负责人、标签、归档恢复实际变化时更新任务最后更新时间；查看、排序及评论操作不更新它，评论单独记录创建和编辑时间 |
| 展示内容 | 卡片显示标题、任务编号、负责人、优先级、截止时间及标签；详情集中编辑字段，并提供描述、评论、操作记录。已完成与归档沿用既有规则，截止时间明确显示时区信息；避免重复、无必要的次级描述 |
| 设备适配 | 桌面支持完整看板和拖拽；手机可查看、新建、编辑、评论、处理通知及切换状态，窄屏提供状态选择入口，不要求依靠横向拖拽才能完成操作 |
