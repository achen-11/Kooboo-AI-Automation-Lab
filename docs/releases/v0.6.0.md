# v0.6.0

本版新增资源与站点归档/舍弃、AI Chat 发送快照、逐屏取证及多轮复评降本，并修复远端 Kooboo 桥接等待、已取消任务重新启动与评测流式结束恢复。升级不会自动恢复已停止任务或改动已有站点。

## 生成会话与远端 Kooboo 兼容

- 生成任务详情“输入与配置 → 发送给 AI Chat”保存每次实际投递的不可变快照、轮次历史、附图 PNG 与绑定任务资料包，明确区分待发送、发送结果待确认、已接受及终态回执。
- 延长跨境/远端 Kooboo 管理端冷启动与桥接就绪等待窗口，在单个任务生命期内保留浏览器静态资源缓存，仅在任务确认完成或取消后裁剪可再生缓存；超时输出页面阶段诊断。
- 发送前同步等待聊天桥接 `canSend` 就绪；若同一页面确认桥接在保存与入队前同步拒绝（如 `Conversation is not ready`），自动回滚预占状态并标记前置拒绝，避免误入 `sending` 死锁，同时对断连后的未知发送继续保持防重发保护。
- AI Site 模板参考研究提示词对缺少 `take_page_screenshots` 的远端 Kooboo 环境保留探测与优雅降级，不阻塞资料建站、旧站升级与迁移场景。

## 逐屏取证与评测效率

- 独立评测接入本地 Playwright `take_page_screenshots` 逐屏稳定采集，支持按游标续采与证据哈希校验，避免长页懒加载与入场动画被整页截图截为空白。
- 拦截评测与来源视觉采集中新开窗口（`target="_blank"` / `window.open`）的非归属导航，消除无主 frame 导航导致的评测崩溃。
- 多轮优化采用增量复评加达标后终审全站复核，分片执行检查点并精简上下文摘要，降低单轮与多轮评测开销。
- 修复 Responses 流式 `response.completed` 后连接关闭误判、首包前瞬断有限重试及 SDK 子进程退出核实；后台 Worker 增加脱敏异常退出诊断日志。

## 资源管理、任务恢复与在线更新

- 资源库与任务中心（生成站/待建站任务）支持**完成归档**、**舍弃**与**移回在列**，提供在列/已完成/已舍弃/全部筛选、原因备注、批量操作及关联级联选项；已归档项阻止误恢复。
- 已确认停止的**已取消**任务支持一键“重新启动”：从未发起建站/投递的生成任务直接重新排队，已投递或已建站任务转入 AI 跟进先核对会话与站点状态。
- 任务中心与详情统一展示执行环境名称；在线更新安装前仅按实际执行占用拦截，历史“停止未确认”记录不再单独阻挡更新。

## 验证与边界

发布前全量类型检查（`tsc` + `vue-tsc`）、920 项 Node 测试（916 项通过、4 项按默认配置跳过）、59 项 Python 采集与打包测试及隔离生产构建均通过；香港远端 Kooboo 生成与跟进链路已完成实测验证。Windows 实机仍待另行验收。
