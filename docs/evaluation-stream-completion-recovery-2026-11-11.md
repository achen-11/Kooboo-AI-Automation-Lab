# 评测流式结束误判与恢复

2026-11-11 排查 Carlux WBS、Car Repair 的评测中断：本地请求账本已经收到用量，但随后记录“SDK 已关闭模型连接”。现有转发器将下游关闭 HTTP 连接统一视为失败，保留 `requestError`；后续请求被拒绝并终止本轮 SDK。评测没有正常走到流迭代结束时，停止状态保持未知，自动跟进拒绝重试并继续预留名额。这与真实评测质量不达标是不同的状态。

Responses 的 `response.completed` 是协议结束标记。提供方可能在此后继续保持 SSE 连接，SDK 则可以关闭已完成响应。修复后先解析终态，收到完成标记后取消剩余上游读取；完成后的正常断开不再写入错误，也不再阻断下一次模型请求。真正发生在终态前的断开仍记录失败和未知用量，不伪造停止确认或成功报告。

`tests-node/usage-proxy-terminal.test.ts` 使用仅绑定回环地址的模拟提供方，发出完成标记后故意保持连接，重现 SDK 读完终态即关闭的行为。修复前该用例稳定失败，修复后同一转发器的下一次请求成功到达上游。对照用例保留终态前断开失败的行为。现有 HTTP 拒绝测试同时更新为当前停止规则：拒绝后不再向上游发送压缩请求，不增加虚构请求或 SDK 汇总用量。

实际恢复后，Carlux 又出现一次真实上游断开（`UND_ERR_SOCKET`）。为避免真实异常退出后仍永久保留停止未知状态，macOS/Linux 评测使用支持的 SDK `codexPathOverride` 启动入口：在沙箱工作区之外记录本次 SDK 的 PID，再以 `exec` 保持进程身份。每次启动前清除上一批 PID，异常后等待并核实该 PID 已不存在；同时仍要求工具服务和浏览器实际关闭。缺失、无效回执、存活进程或权限不足均不能被判为停止。Windows 保留原有保守分支，未宣称已验证自动退出确认。主 Worker 是否存在不能代替 SDK 退出证据。

对独立评测中尚未向 SDK 转发任何响应内容的 socket / connect / reset / timeout 故障，转发器原地最多重试两次，间隔 300ms。每次尝试单独记账，保留未知用量，重试前重新检查工作流预算。不重放部分响应流，不重试 HTTP 拒绝，不应用于跟进或可能改站的操作。

验证：相关评测、跟进、预算、计费及真实假进程退出测试共 81 项通过，1 项真实 Codex 环境测试默认跳过；生产构建和服务端 TypeScript 编译通过。没有执行管理界面浏览器验收。真实任务的达标状态由后续独立报告决定，测试通过不能代替真实达标。

本次恢复遵循用户指定范围：10 个模板各保留最新建站主任务，较早的重复任务停止推进；每条任务链的累计费用上限为人民币 15 元，沿用原 85 分目标、规则快照和完整度验收。运行数据、进程核查记录及本次恢复范围保存在本机 `.data/maintenance-2026-11-11/`，不进入 Git。重启前保留数据库快照和配套加密配置/主密钥，原站点、证据和历史累计用量保留。

第三次维护切换已确认 42 个所属进程全部退出，再启动编译后的服务并检查 API、Worker 健康。真实 Hyper Auto Care、Carlux 独立评测已出现首段响应前的 socket 断开，有限重试后在同一评测中收到成功响应并继续，验证了该恢复路径；不据此认定任务质量达标。Car Wash Lite 因此前多次维护用尽旧跟进次数时，仅为原会话核对增加三次跟进机会，保留全部累计费用与未知用量，并继续保持每条 15 元上限。

约北京时间 05:15 后，多条执行同时停止更新；05:30 检查确认 API 存活而后台 Worker 已退出。此前子进程输出被忽略，没有足够证据判定退出原因。新增私有 `background-worker-failures.jsonl`：通过 `uncaughtExceptionMonitor` 记录经过现有脱敏器处理且限长的异常，并由父进程记录非预期退出的 code、signal、PID。监控只保留诊断，不吞错、不自动重启或重放生成。真实子进程拒绝测试验证日志脱敏、0600 权限、故障后 API 仍可访问且 Worker 健康为 false；后台进程测试 4 项、服务端类型检查和生产构建通过。

第四次切换前再次核对旧 Worker、记录的 SDK PID 与所属 Chromium 均已退出，保存 SQLite 快照及进程审计，再接续原评测任务与批次。Car Repair 第四轮远端生成的结果仍需原会话查证，因此只排入跟进，不重发委托。启动后 API、Worker、浏览器依赖均健康，解除本次维护标记继续队列。诊断补丁不代表已查明或修复此次退出原因；后续以实际故障记录为依据。
