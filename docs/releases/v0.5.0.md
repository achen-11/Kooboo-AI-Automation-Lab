# v0.5.0

本版重点改进 AI Site 模板的评测效率、修复后复评及中断恢复。更新不会自动恢复已停止任务或付费重跑历史报告。

## 评测与复评

- 程序生成路径、查询参数、双端、HTTP 和页面稳定状态的事实表；具有明确记录契约的数据集由程序分页对账数量、主键及必填字段。
- 修复后优先复验上次问题、未验证项及当前证据发生变化的范围。只有绑定与当前证据完全一致、已通过且达到目标的判断才可继承；交互及业务判断保留独立复验。
- 每个旧问题记录已解决、仍存在或未验证，报告展示复评基线、继承和独立复验明细。
- 程序继续按完整冻结清单与双端采集当前证据，合并后仍按原全部范围验收；缺少证据不会视作通过。
- 提供有界的源码预览、分批评测字段骨架和图片区域索引，减少重复读取、截图查找及工具输出。

## 中断恢复

- 恢复已停止的独立评测时直接复核检查点，避免额外的 AI 恢复决策；执行停止尚未确认时仍阻止恢复。
- 长图连续切片并分批传递，持久保存批次和回执；未知发送结果不重复投递。
- 修复分析先检查真实图片，再计入模型尝试；保留历史用量及未知请求预占。
- 跟进上下文省略重复 SOP 和历史正文，完整记录仍可追溯。

## 耗时与成本

- 提供“耗时与成本” Dashboard，支持日期范围、阶段堆叠、任务效率及自定义时段对比。
- 区分首次生成和修复生成，调整累计执行时间口径；筛选更新局部数据。
- 改进费用与耗时展示及主题对比度。

## 验证与边界

发布前相关 Node 测试共 236 项：234 项通过，2 项按默认配置跳过。服务端类型检查与生产构建通过。

测试使用本机 mock 和固定证据，未调用真实模型或生成站，未执行浏览器验收。本版不承诺固定的费用或耗时降幅，需通过后续真实任务和 Dashboard 对比确认。
