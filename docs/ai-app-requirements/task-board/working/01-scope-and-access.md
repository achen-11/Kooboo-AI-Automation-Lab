# 模块一：产品范围与项目访问边界

状态：讨论中。本文件不作为生成资料上传。

## 已确认

系统支持多个项目，每个项目有独立看板与成员。参见 D004。

项目内仅设管理员与成员，暂不提供只读访客。项目及任务仅项目成员可见，由项目管理员添加成员。参见 D005、D006。

所有登录用户都可以创建项目，创建者自动成为该项目管理员。参见 D007。

## 已讨论的候选方案

### 项目内角色

本轮曾建议首版采用项目管理员、成员、只读访客三种身份；用户最终选择仅项目管理员与成员。下表保留为讨论历史，其中访客未纳入首版，具体任务权限仍待讨论。

| 候选身份 | 建议职责；尚未确认 |
| --- | --- |
| 项目管理员 | 维护项目、管理成员及看板规则；具体任务权限后续确认 |
| 成员 | 参与项目并处理任务；创建、编辑、分配与删除范围后续确认 |
| 只读访客 | 查看获准访问的项目内容，不修改项目或任务 |

最终选择仅设项目管理员和成员，暂不提供只读访客。是否需要系统级管理员及其职责仍待确认。

### 项目可见范围

用户已选择仅项目成员能看到项目及其任务，由项目管理员添加成员。另一候选为全部登录用户可发现和查看项目，加入后才能操作，未被采用。

已选策略会影响项目列表、直达链接、任务详情及业务操作的访问规则。具体越权反馈和验证要求后续细化。

## 整理观察

先确定项目边界，再决定角色和模块行为。每轮聚焦相关选择，确认后才进入正式资料；不要凭“任务看板”这个产品名称自动补全权限、流程和字段。
