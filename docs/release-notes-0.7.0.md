# v0.7.0

AI Site 模板生成接入“参考分析 → 生成 → 逐项独立检查 → 按需修复复验”的完整调度流程，为批量模板工作提供固定输入、检查集和证据依据。

- **生成前分析**：支持只有参考站 URL 的模板资源。Lab 先采集桌面、移动端画面与布局，形成页面、语义区块、双端约束和交付清单；关键来源缺口会保留进度并阻止建站。有效来源证据、分析草稿和检查点可恢复复用。
- **版本化 checklist**：新任务冻结检查集版本，结果逐页面、区块、视口记录通过、失败、未验证或不适用。规则页支持编辑和发布新版本；基线、采集范围、问题状态和证据可在任务中查看。原报告与旧任务保持兼容。
- **设计师规范**：基础 prompt 强调模板 DNA、可读性、内容一致性与独立验收；初始检查集包含原 8 项区块检查和 6 组设计规范。导航形式、价格列数和固定间距按模板适用，避免统一所有模板风格。动效组首版非必过、权重为 0，缺少动态证据保留未验证。
- **修复与复验**：已有自动优化授权时，将已证缺陷批量交回原站、原会话。按当前依赖和区块变化决定局部或扩大取证，保留继承证据的原任务和修订；问题仅由独立复验关闭，达标后结束。来源或证据不足不伪装成站点缺陷交给生成方修复。
- **经验开关**：新安装默认关闭使用经验和沉淀经验。全局关闭后，历史选择与基线内的经验不再注入新请求，排队复盘不再调度，手动复盘也会提示关闭状态。历史记录与费用保留，已在途请求不会被强制终止。
- **跟进边界**：需要用户上传文件时，自动跟进不能伪造上传答案；参考视觉证据失败或需要更换范围、来源时，应保留阻塞和可操作的下一步。

## 升级后操作

1. 沿用平台的“检查更新 → 下载并更新”。完整数据、主密钥、历史任务和规则版本保留。
2. 其他安装已有检查集时，不会被自动覆盖。到规则页编辑为新版本，点击“加入设计规范”，审阅并发布；后续新建模板任务会冻结新版本，旧任务不会自动转入新流程。
3. 升级保留已有经验设置。若要暂停经验使用和复盘，请在系统设置中同时关闭“使用经验”和“沉淀经验”。
4. 新流程用于新建且尚无目标站的 AI Site 模板生成任务。已有站点继续生成和旧任务保留原流程，改变参考或范围应创建新任务。

## 验证与边界

已完成针对性自动化回归与生产构建；具体发布检查见 `release-validation-0.7.0.md`。模拟通过不代表真实模型的视觉判断、完整站点交付或 Windows 实机已验收。当前模板自动流程为桌面/移动两种视口，不宣称已覆盖设计材料要求的三档宽度。

本发行附件只包含 Automation Lab。Kooboo 的截图预热和 `process_image` 裁切/切片工具属于独立仓库改动，需另行更新 Kooboo；远端截图服务也需单独部署。Lab 自身继续使用逐屏证据采集。批量开始前应先用少量有代表性的站点验证真实生成、检查和修复闭环。
