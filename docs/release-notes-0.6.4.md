# v0.6.4

修复跟进预算耗尽后恢复任务立即再次中断，以及经验复盘反复阻塞恢复的问题。

- **恢复跟进预算**：人工恢复已耗尽次数、时间或 token 预算的任务时开启新的跟进窗口，保留累计次数、耗时、用量和未知费用。执行记录区分本轮与累计数据。
- **经验复盘与模型错误**：相同中断不再因时间变化重复复盘；模型额度、鉴权及预算保护中断不自动发起付费复盘。模型返回 HTTP 402 时立即提示处理账户或服务配置，避免耗尽全部跟进次数。
- **强制中断与状态同步**：后台取消等待执行服务回执；强制恢复处理同工作流排队中的复盘，取消已结束的经验学习返回当前状态。恢复按钮与经验学习记录同步刷新。

已通过针对性自动化测试、服务端类型检查及生产构建，并使用排障包中的任务和预算记录隔离回放，确认旧版立即中断、新版可进入跟进。回放使用模拟模型行动，不代表原站生成完成或真实远端会话验收。
