# 产品范围与项目访问边界

状态：需求已整理，纳入 v1.0-review 整体复核；尚未生成或运行验收。

## 系统名称

任务看板管理系统。

## 交付范围原则

- 按当前已确认需求准备完整交付，不预设首版、MVP 与后续功能阶段；不以迭代计划为理由默认删减功能。
- 后续仅在实际发现遗漏时补充；明确排除的功能继续排除，不因完整交付而自动扩展。
- @提及、站内通知、邮件通知及项目内“仅看我的任务”必须实现；不提供跨项目“我的任务”汇总、子任务、跨项目移动或独立附件。

## 项目组织方式

- 系统支持多个项目。
- 每个项目有独立看板与成员。

## 项目内身份

- 项目内设项目管理员与成员两种身份。
- 不提供只读访客。

## 用户账号与登录

- 复用 Kooboo 已有账号体系及登录身份，用户标识、显示信息和邮箱沿用平台账号。
- 登录、退出及账号维护沿用 Kooboo 能力；不另建应用账号、密码或独立的邮箱注册、验证及找回密码体系。
- 项目成员及项目内管理员、成员身份仍由本应用按项目维护；复用平台登录不自动赋予项目访问或管理权限。
- 项目管理员从 Kooboo 已有用户中添加项目成员，只管理该项目成员关系，不因此获得平台账号管理权限。

## 项目创建

- 所有登录用户都可以创建项目。
- 创建者自动成为该项目管理员。

## 访问边界

- 项目及其任务仅该项目成员可见。
- 项目管理员负责添加成员。

## 已确认的协作范围

- 任务描述与评论正文支持 Markdown 及正文图片；图片先上传取得链接，正文保存链接，不内嵌 Base64。
- 取消任务与评论的独立附件功能。
- 使用独立任务，不提供子任务或父子任务层级。
- 任务固定属于创建时的项目，不支持跨项目移动。
