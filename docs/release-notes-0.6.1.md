# v0.6.1

本版本完善资料导入后的建站命名、输入展示与名称冲突恢复。

- 创建生成任务时检查实际使用的子域名，包含连字符（`-`）时显示错误并阻止提交；香港根域名 `-shawnchen-hk.kooboo.io` 可正常使用。
- 沿用外部 Admin 导入的站点名称、子域名及根域名。建站前发现名称或子域名被占用时，为对应字段自动添加 `_1`、`_2` 等后缀，并保存最终选择。
- 任务详情“输入与配置”展示导入时的名称、子域名及根域名，以及实际建站配置；兼容历史任务的信息展示。
- 尚未发出建站请求、因名称冲突而停止的任务，可点击“自动调整名称并继续”，保留原任务输入和检查点，检查可用名称后重新加入队列。建站结果不确定的任务继续沿用原有核验流程。

验证：71 项相关测试、服务端 TypeScript 检查及生产构建通过。未执行真实模型、远端 Kooboo 建站、浏览器或 Windows 实机验收。
