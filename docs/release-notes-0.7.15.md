# v0.7.15：队列诊断与停止确认

任务中心新增“队列诊断”，可查看自动执行、后台就绪与维护状态，分别列出生成／评测的实际执行数、占位数和并发上限。

排队任务现在可以查看等待原因和阻塞任务，包括并发占满、未确认停止、同站优化／交付、换绑域名、迁移读取及定时退避。后台退出时明确显示未就绪，页面在线不再被当作后台正在执行。

对已经核实原 Kooboo 会话及相关执行均已停止的记录，可以逐项“确认已停止”。系统重新检查本机执行归属及任务状态，确认后保留原站点、输入、会话、证据与用量；不会自动恢复原任务，也不会重发生成或迁移请求。需要继续原任务时，进入原任务使用恢复入口。交付回执未知时仍需按原交付流程核查，停止确认不代表迁移结果已确认。

本版本从正式版 v0.7.13 制作，只增加队列诊断及确认保护，不包含开发工作区中的后台负责人、新交付检查或外部接续流程。既有任务以及新建“仅首页”的资料建站／旧站升级均沿用稳定版流程。0.7.14 已被开发工作预留，本维护版使用独立版本号 0.7.15。

升级不会自动解除历史未知执行占位，也不会自动清理或重建排队任务。升级后如仍排队，打开“任务中心 → 队列诊断”，先核查原因，再逐项处理。请通过原安装目录的 `npm start` 启动，在侧栏版本号或系统设置中检查更新；受管理更新继续保留完整数据备份与失败回滚。有实际执行时需先等待结束，或正常停止并核实执行结果。

验证覆盖针对性 Node 测试、组件测试、服务端和局部 Vue 类型检查、生产构建，以及 0.6.4 合成数据升级读取与恢复。未进行 Windows 实机在线升级、真实模型建站或浏览器验收，详情见 `docs/release-validation-0.7.15.md`。
