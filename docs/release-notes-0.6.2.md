# v0.6.2

修复香港环境“自动调整名称并继续”失败，以及建站根域名缺少前导 `-` 的问题。

- 兼容 Kooboo 原生 v2 可用性接口：正确识别成功的 `200 / null` 和明确的名称占用响应，重名后继续尝试 `_1`、`_2` 等后缀。权限、连接及其他未知错误仍阻止建站。
- 当根域名由名称和分隔符字段组成时，选择、保存及任务详情统一保留 `-shawnchen-hk.kooboo.io`；兼容历史任务中省略前导 `-` 的配置。
- 保留建站结果不确定时禁止重复创建的规则。

已在配置的香港环境只读核对接口协议；未执行真实建站、模型、浏览器或 Windows 实机验收。本版本不包含尚未验收的 iframe 实时对比改动。
