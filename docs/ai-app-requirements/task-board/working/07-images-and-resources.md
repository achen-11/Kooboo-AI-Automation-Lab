# 正文图片与资源清理

状态：资源业务规则已确认（D110—D113），不作为生成资料上传，正式需求见 [正文图片与资源清理](../package/07-images-and-resources.md)。

## 已确认的前提

- 描述与评论采用 Markdown 文字及正文图片，已取消独立附件管理。
- 图片先上传取得链接，持久化正文不保存 Base64、data URL 或临时本地预览地址。
- 图片遵守项目成员权限，归档后仍可查看但不能修改正文。
- 评论正文仅作者可编辑，任务描述按既有任务编辑权限处理。
- 日志不备份评论全文或图片，首版不做描述正文版本历史。

## 已确认的整组规则

用户对通知及图片整组回复“其他的按建议即可”，仅将 @提及改为必做并修正首版分阶段表述；以下图片规则均已确认并进入正式需求。

| 主题 | 已确认规则 |
| --- | --- |
| 插入方式 | 支持选择图片、粘贴截图及拖入图片；统一先上传取得链接再插入，上传中有进度或状态，失败明确提示并可重试，不把占位图当成有效图片 |
| 格式与预览 | 支持 JPG、PNG、WebP、GIF，单张不超过 10 MB；正文内展示，点击可放大预览；沿用正文编辑与项目查看权限，不另设附件管理入口 |
| 保存与移除 | 图片增删属于对应正文编辑；存在未完成或失败的图片上传时不允许提交包含这些占位图的正文，用户可重试或移除后保存；从正文移除图片只先移除引用 |
| 资源清理 | 删除评论、真删除任务或项目后清理不再被有效正文引用的图片；同一图片仍被其他有效内容引用时不能误删；取消编辑或未保存的上传可延迟清理，不能干扰正在编辑的有效上传；归档不清理图片 |
