# 模块五：查询、筛选与个人任务视图

状态：查询、排序及精确截止时间已确认，项目内“仅看我的任务”必做，跨项目汇总排除。本文件保留讨论过程；下文按日期逾期的旧规则已由 D123 替代，正式需求见 [查询、筛选与任务视图](../package/05-query-and-my-tasks.md)。

范围修订：下文“我的任务可选”记录当时的 D086，现已被 D114、D115 替代。用户当前明确不做跨项目汇总，但必须保留项目内本人负责人快捷筛选，不能把两者混为一谈。

## 已确认的前提

- 查询只能覆盖用户当前有访问权的项目与任务，退出或被移除后不再可见。
- 常规任务看板及列表默认隐藏归档任务，只有主动查看或查找归档任务时才展示；本轮确认项目内主动进入的归档任务列表。
- 标签是独立筛选维度，不参与看板列排布。
- 完成由各项目指定的完成列判断，不能仅凭列名判断；项目间列与标签相互独立。
- 截止日期仅精确到日期；逾期采用系统统一时区，截止次日起未完成任务显示逾期，具体时区仍待确定。

用户回复“符合预期, 我的任务可做可不做”。前三项按原建议确认，“我的任务”改为可选项，见 D083—D086，已同步正式需求。

| 主题 | 已确认规则 |

## 已确认的整组规则：查询细则

用户回复“按建议即可, 任务排序的话按建议默认最新创建在前, 不过支持手动拖拽排序”。查询细则按建议确认，并补充列表手动拖拽，见 D087—D094，已同步正式需求。这里按上一轮区分看板和列表的上下文理解：最新创建在前为列表默认排序，看板已有列内排序与新任务入列末尾规则继续有效。

| 主题 | 已确认规则 |
| --- | --- |
| 关键词匹配 | 标题或描述任一包含关键词即命中，忽略英文字母大小写；描述按可阅读的文字内容搜索，不匹配 Markdown 标记及图片链接地址 |
| 条件组合 | 搜索与不同筛选维度之间同时满足；同一维度多选时满足任一项即可，多个标签也按任一标签匹配 |
| 截止日期 | 支持起止日期范围，包含起止当天；可单独筛选“未设截止日期”；按逾期筛选时，无截止日期及已完成任务均不算逾期 |
| 归档查询 | 项目内提供主动进入的“归档任务”列表，支持同样的搜索和筛选；常规视图及其搜索不混入归档任务 |
| 视图与排序 | 看板保留配置的列顺序和手动任务顺序，筛选只隐藏不匹配任务；列表默认按创建时间倒序，可按截止日期或优先级排序，按截止日期排序时无日期任务排末尾；用户补充列表支持手动拖拽排序 |
| 筛选后操作 | 仍可打开任务、按既有权限编辑或切换状态；筛选生效时暂停同列拖拽排序，跨列移动仍按目标列末尾规则；操作后不再匹配的任务退出当前结果 |
| 保留与清空 | 同一项目切换看板和列表时保留查询条件，提供一键清空；切换项目重置为该项目默认条件，不要求跨会话记忆 |
| 数量与空结果 | 展示当前匹配任务数，看板列数量按筛选结果计算；无结果显示空状态并允许清空条件，不改变底层任务数据；首版不增加独立统计报表 |

归档任务仍只读，不因进入查询结果而扩大编辑权限；归档项目依然可主动查看，项目访问范围沿用既有规则。“我的任务”为可选项，本组不增加其跨项目配置要求。上述排序和查询实现方式留到生成阶段决定。
