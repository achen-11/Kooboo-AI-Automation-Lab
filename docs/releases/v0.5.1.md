# v0.5.1

修复 Kooboo 新站子域名包含连字符的问题，并为已有生成站提供域名换绑入口。

- 新站名称与子域名统一使用 `auto_` 前缀，任务 ID 中的连字符替换为下划线；新任务在发出建站请求前固定名称，旧任务继续核对原创建结果，避免重复建站。
- 在任务中心、任务详情“更多”和资源详情生成站卡片中提供“换绑域名”。默认建议修正后的子域名，并支持选择环境可用根域名。
- 确认实际绑定成功后同步更新平台访问地址，保留站点 ID、站点内容及原有绑定；后续刷新继续使用选定域名。
- 换绑期间阻止同站执行和并发换绑；请求回执丢失时先核对已有绑定，避免重复提交。历史评测报告和证据保留，新地址需独立评测。
- 新建任务可沿用环境默认根域名，或在任务中选择其他可用根域名。

已有站点不会自动批量换绑。请从上述入口逐站处理；正在生成、评测、优化或交付的站点需先等待或停止对应执行。

本次域名修复与换绑功能已由用户验收通过。发布前在干净源码目录执行针对性回归、服务端类型检查、生产构建及安装包完整性校验。Windows 实机和接收端在线安装仍需按实际环境验证。
