# v0.6.3

发布实时双站同屏对比（iframe 实时对比）、同工作流活动执行检测与强制中断恢复，以及资源导入与建站配置说明更新。

- **实时对比弹窗**：任务详情、站级报告与评测报告新增“实时对比”弹窗，支持原站与生成站同屏 iframe 并排对照，附带嵌入响应头预检、不可嵌入时的评测截图回退及同步滚动控制。
- **活动执行检测与强制中断恢复**：顶部“恢复任务”无条件检查同工作流内仍在运行的任务与经验学习记录，直接暴露阻塞状态；支持在顶部或经验学习列表中强制中断执行中 / 排队中的任务与经验复盘并安全保留预算预占后继续恢复。
- **资源导入与建站配置说明**：补充 `siteName`、`subDomain`、`rootDomain` 字段规范与香港根域名前导 `-` 说明，同步更新文档、资源详情及系统设置示例。
