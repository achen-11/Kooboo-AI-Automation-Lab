# Project instructions

- This Kooboo site is the active Site Evaluator project. Maintain it here; the older `../ai_site_evaluator` is an archived source and must not be modified or started unless the user explicitly asks.
- Read `README.md` and `.kooboo-ai/specs/frontend.md` before changing deployment or resource layout.
- Edit `backend/`, `frontend/src/`, and `scripts/`; `src/` is generated by `npm run build` and is not committed.
- Do not commit `.env`, vault keys, runtime data, or generated `kooboo.d.ts`. Use the verified, limited `backend/k-types.d.ts` for server bindings.
- Preserve the running site's vault key. Never overwrite target `.env` when copying changes from a temporary workspace.
- Validate changes with focused tests, build and Preflight. Browser control and visual acceptance require explicit user permission.
- Publish only the affected generated resources. Do not modify Kooboo core for this project's requirements.
