# 统一权限矩阵

身份均指当前项目，Kooboo 平台登录与其他项目管理员身份不自动赋权。未登录、非成员及已离开者不能读取本项目任务、正文图片、历史或通知内容；服务端同时约束直接请求与链接访问。

## 进行中项目

“正常任务”指未归档任务，包含已完成任务。归档任务只允许查看、恢复及管理员真删除，其他编辑均禁用。

| 操作 | 项目管理员 | 普通成员 | 非成员/已离开 |
| --- | --- | --- | --- |
| 查看项目、正常/归档任务、正文图片、项目及任务记录 | 允许 | 允许 | 禁止 |
| 修改项目信息 | 允许 | 禁止 | 禁止 |
| 添加、移除成员、调整角色 | 允许，至少一管理员 | 禁止 | 禁止 |
| 主动退出 | 允许，须有其他管理员 | 允许 | 无成员关系可退出 |
| 列配置、颜色、默认列与完成列 | 允许，遵守空列等约束 | 禁止 | 禁止 |
| 创建标签并选颜色 | 允许 | 允许 | 禁止 |
| 标签改名、改颜色、删除 | 允许 | 禁止 | 禁止 |
| 创建、编辑、分配正常任务，应用/移除标签 | 允许，任意本项目任务 | 允许，任意本项目任务 | 禁止 |

## 个人与系统能力

- 所有登录用户可创建新项目；不必先成为其他项目成员。
- 用户只能管理自己的站内已读状态、邮件开关和显示时区；不能读取或改写他人通知。
- 任务负责人、创建人、评论作者不获得额外项目管理权限；评论作者的正文编辑权限不能转授给管理员。
- 业务成功保存后由系统记录日志及产生通知；无用户可直接改写或单独删除历史记录。真删除任务或项目时按对应范围级联清除。
- 失权后停止展示数据，已发邮件无法撤回；邮件中的链接仍校验当前身份与权限。

本矩阵汇总 01—10 的规则，不覆盖各模块更具体的保护条件。管理员自行降级及并发成员管理采用整理默认 R02。
