# v0.7.0 发布验证

日期：2026-11-13（Asia/Shanghai）。

## 发布范围

基于 v0.6.4，接入新建 AI Site 模板的前置参考分析、冻结基线、版本化检查集、检查界面与独立修复复验，加入设计师规范和全局经验开关约束。保留 v0.6.4 的预算恢复、站点名称恢复、实时对比及工作流停止确认行为。

发行附件仅包含 Automation Lab。Kooboo 的截图预热和图片处理工具另行提交，不纳入本 ZIP；个人数据、凭据、主密钥和未纳入发布的历史讨论文档不进入附件。

## 源码验证

- 完整 Node 回归：980 项，976 通过、4 项默认跳过、0 失败。包含模板新流程、历史评测、投递与恢复、预算、经验开关、在线更新和启动器切换/回退。
- 模板前端逻辑与组件测试：8 项全部通过；使用 Vue 测试渲染器，未做浏览器视觉验收。
- Python 打包边界测试：7 项全部通过。
- `npm run build` 通过，包含服务端 TypeScript 构建；前端保留现有包体积提示。未执行全量 vue-tsc / lint。
- `git diff --check` 通过。

首次全套回归暴露两个测试前置不匹配：预算恢复测试依赖过去默认启用经验沉淀，实时对比组件的 API 替身缺少新增依赖。测试现已显式启用待验证的经验行为，并补全组件替身；保留对生产默认关闭和关闭后不调度的独立断言，修正后全套回归通过。

## 正式包验证

正式更新包必须从本版本的干净提交制作；打包器在临时目录重新构建，核对锁定依赖，不复制开发目录的 `.data/`、密钥或 `node_modules`。发布前再次核对 ZIP、更新清单、构建信息和版本标签使用同一提交，检查逐文件哈希，并使用解压后的真实受管理启动器做临时数据目录的本机启动检查。

启动检查只创建空白临时配置，不迁入本机运行数据、不启动真实生成任务、不连接模型或业务站点。检查首页、本机会话、Worker 就绪、模板检查集接口、经验默认关闭和运行版本；结束时关闭启动器及其后台进程。

## 验收边界

没有执行 Windows 实机安装、完整真实模型模板生成或正式远端环境验收。真实视觉质量、误报/漏检、耗时和费用仍需小批试跑确认；本版本不宣称 200 个模板可直接无人值守完成。

新安装初始检查集为 14 项；升级保留已有检查集，需在规则页补充设计规范并发布新版本。升级同样保留已有经验设置，暂停经验时需关闭两个开关。旧任务不自动转入新模板流程，不改写历史报告和证据。
